# Terrain Segmentation

APS360 individual project: design and train a convolutional neural network to segment Mars rover images into soil, bedrock, sand and big rock.

## Status

Proposal preparation. Training and baseline code have not yet been implemented. No model results are claimed.

## Structure

- `src/`: project implementation.
- `notebooks/`: experiment notebooks.
- `reports/`: finalized proposal and report artifacts.

These directories currently contain placeholders only.

## Dataset

[AI4MARS original paper](https://openaccess.thecvf.com/content/CVPR2021W/AI4Space/html/Swan_AI4MARS_A_Dataset_for_Terrain-Aware_Autonomous_Driving_on_Mars_CVPRW_2021_paper.html)

[Public dataset mirror](https://huggingface.co/datasets/hassanjbara/AI4MARS)

On the current machine the downloaded data is at `../data/ai4mars`, outside this repository. A clone on another machine will need a separately downloaded dataset. Data and trained weights should not be uploaded to this repository.

## Documents

The working LaTeX proposal remains at `../TOPIC_SELECTION_REPORT.tex` in the course folder so the current editor stays connected to it. After finalizing it, place the submission PDF in `reports/`. If including LaTeX source, also include `APS360.sty` and `proposal_assets/image1.png`, preserving the relative image path.
